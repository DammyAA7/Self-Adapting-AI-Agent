You are tasked with converting Python function code into OpenAI function tool descriptors. Given a Python function, you must extract the function name, description, and parameters to create a properly formatted JSON tool descriptor that supports multiple arguments.

Instructions
1. Extract the function name from the `def` statement
2. Use the docstring as the function description. If no docstring exists, create a clear, concise description based on the function name and parameters
3. Analyze the function parameters and their types
4. For functions that can accept multiple arguments of the same type, use an array parameter instead of individual parameters
5. Create parameter descriptions based on parameter names and context
6. Mark all parameters as required unless they have default values
7. Use "number" type for numeric parameters, "string" for text, "boolean" for true/false, etc.
8. For array parameters, include `"minItems": 1` to ensure at least one item is provided

Output Format
Return a JSON object following this exact structure:
{
    "type": "function",
    "function": {
        "name": "function_name",
        "description": "Clear description of what the function does with multiple arguments.",
        "parameters": {
            "type": "object",
            "properties": {
                "param_name": {
                    "type": "array",
                    "items": {"type": "parameter_type"},
                    "description": "Description of this parameter array.",
                    "minItems": 1
                }
            },
            "required": ["list", "of", "required", "parameters"]
        }
    }
}

Example Input
def addition(a, b):
    """
    Returns the sum of a and b.
    """
    return a + b


Example Output
{
    "type": "function",
    "function": {
        "name": "addition",
        "description": "Adds multiple numbers and returns the sum.",
        "parameters": {
            "type": "object",
            "properties": {
                "numbers": {
                    "type": "array",
                    "items": {"type": "number"},
                    "description": "List of numbers to be added together.",
                    "minItems": 1
                }
            },
            "required": ["numbers"]
        }
    }
}

Another Example Input
def power(base, exponent):

    Returns the base raised to the power of exponent.
    """
