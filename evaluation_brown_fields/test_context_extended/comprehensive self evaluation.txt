Task 6: Financial Portfolio Risk Calculator
Domain: Finance / Investment Management
Session Structure:
● Session 1: Generate calculate_stock_volatility() for statistical analysis
● Session 2: Generate portfolio_risk_assessment() using volatility function
Session 1 Specification:
Goal: Create a function that calculates 30-day stock price volatility
Algorithm:
1. Calculate daily returns: return[i] = (price[i] - price[i-1]) / price[i-1]
2. Calculate mean return: mean = sum(returns) / len(returns)
3. Calculate variance: var = sum((r - mean)² for r in returns) / len(returns)
4. Return standard deviation as percentage: sqrt(variance) × 100
Edge Cases:
● Empty price list → return 0.0
● Single price → return 0.0
● Handle negative prices gracefully
Session 2 Specification:
Goal: Create portfolio-level risk using individual stock volatilities
Input Format:
portfolio = {
'AAPL': {'prices': [150.0, 152.0, 148.0, 155.0], 'allocation': 0.4},
'GOOGL': {'prices': [2800.0, 2820.0, 2790.0, 2850.0], 'allocation': 0.6}
}
Algorithm:
1. For each stock: - Extract price history - Call calculate_stock_volatility(prices) - Multiply volatility by allocation percentage
2. Sum all weighted volatilities
3. Return overall portfolio risk

Task 7: IoT Sensor Data Pipeline
Domain: IoT / Smart Home Systems
Session Structure:
● Session 1: Generate parse_sensor_reading() for protocol parsing
● Session 2: Generate aggregate_room_temperature() using parser
Session 1 Specification:
Protocol Format: 'T:25.5|H:60|TS:1234567890'
Field Definitions:
● T = Temperature in Celsius (float)
● H = Humidity percentage (float)
● TS = Unix timestamp (integer)
Parsing Requirements:
# Input: 'T:25.5|H:60|TS:1696800000'
# Output: {'temperature': 25.5, 'humidity': 60.0, 'timestamp': 1696800000}
# Malformed input: 'T:invalid|H:60|TS:abc'
# Output: {'temperature': None, 'humidity': 60.0, 'timestamp': None}
Session 2 Specification:
Goal: Aggregate temperature readings with time filtering
Algorithm:
1. Parse all raw sensor readings using parse_sensor_reading()
2. Find most recent timestamp
3. Filter readings within last 60 minutes (3600 seconds)
4. Calculate average temperature from filtered readings
5. Return rounded to 2 decimal places
Edge Cases:
● No valid readings → return 0.0
● All readings older than 60 minutes → return 0.0
