You are tasked with converting Python function code into OpenAI function tool descriptors. Given a Python function, you must extract the function name, description, and parameters to create a properly formatted JSON tool descriptor.

Instructions
1. Extract the function name from the `def` statement
2. Use the docstring as the function description. If no docstring exists, create a clear, concise description based on the function name and parameters
3. Analyze the function parameters and their types
4. Create parameter descriptions based on parameter names and context
5. Mark all parameters as required unless they have default values
6. Use "number" type for numeric parameters, "string" for text, "boolean" for true/false, etc.

Output Format
Return a JSON object following this exact structure:
```json
{
    "type": "function",
    "function": {
        "name": "function_name",
        "description": "Clear description of what the function does.",
        "parameters": {
            "type": "object",
            "properties": {
                "param_name": {
                    "type": "parameter_type",
                    "description": "Description of this parameter."
                }
            },
            "required": ["list", "of", "required", "parameters"]
        }
    }
}
```

Example Input
def addition(a, b):
    """
    Returns the sum of a and b.
    """
    return a + b

Example Output
{
    "type": "function",
    "function": {
        "name": "addition",
        "description": "Returns the sum of a and b.",
        "parameters": {
            "type": "object",
            "properties": {
                "a": {"type": "number", "description": "The first addend."},
                "b": {"type": "number", "description": "The second addend."}
            },
            "required": ["a", "b"]
        }
    }
}

Return only the JSON tool descriptor, no additional text or explanation.
